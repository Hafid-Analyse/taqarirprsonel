# تقاريري — دليل التركيب

تطبيق لكتابة تقارير الجلسات والندوات والتكوينات واليوميات، ومتابعة القرارات.
الخادم: Google Apps Script + Google Sheets | الواجهة: GitHub Pages

## محتوى الحزمة

| الملف | دوره |
|---|---|
| `Code.gs` | الخادم: يُلصق في Apps Script المربوط بالشيت |
| `index.html` | التطبيق كاملاً |
| `sw.js` و `manifest.json` | العمل دون إنترنت والتثبيت على الهاتف |
| `lib/` | مكتبتا تصدير الصورة وPDF (محلية) |
| `fonts/` | خط Tajawal (محلي، يعمل دون إنترنت) |
| `icon-192.png` و `icon-512.png` | أيقونة التطبيق |

## الخطوة 1: الشيت والخادم

1. أنشئ Google Sheet جديداً وسمّه مثلاً «تقاريري».
2. من القائمة: **Extensions ← Apps Script**.
3. احذف المحتوى الموجود والصق كامل محتوى `Code.gs`، ثم احفظ.
4. اختر الدالة `setup` من القائمة أعلى المحرر واضغط **Run**، ووافق على الأذونات. ستظهر أوراق: Reports و Decisions و People و Settings.
5. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
6. انسخ رابط Web app (ينتهي بـ `/exec`).

## الخطوة 2: الواجهة على GitHub Pages

1. أنشئ مستودعاً جديداً (مثلاً `taqarir`).
2. ارفع كل الملفات والمجلدين `lib` و `fonts` كما هي.
3. **Settings ← Pages ← Branch: main / root ← Save**.
4. افتح الرابط بعد دقيقة.

## الخطوة 3: أول دخول

- الصق رابط `/exec`، واكتب رمزاً سرياً من 4 إلى 8 أرقام.
- **الرمز الذي تكتبه أول مرة يصبح هو رمزك.**
- على الهاتف: من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» ليصبح تطبيقاً.

(اختياري) لتجنّب لصق الرابط في كل جهاز: ضعه في `index.html` في السطر `const DEFAULT_API = '';`

## ملاحظات مهمة

- **تحديث كود الخادم:** بعد أي تعديل على `Code.gs` اذهب إلى **Deploy ← Manage deployments ← ✏️ ← Version: New version**، فيبقى الرابط نفسه.
- **نسيت الرمز؟** شغّل الدالة `resetPin` من محرر Apps Script، ثم ادخل برمز جديد.
- **الحماية:** الرمز محفوظ مشفّراً في خصائص السكربت وليس في الشيت. وبعد 5 محاولات خاطئة يُقفل الدخول 10 دقائق.
- **دون إنترنت:** كل ما تكتبه يُحفظ على الجهاز كل 3 ثوانٍ، ويُرسل للشيت تلقائياً عند عودة الاتصال. المؤشر أعلى الشاشة يبيّن الحالة، والضغط عليه يطلب مزامنة فورية.
- **تحديث الواجهة:** بعد رفع نسخة جديدة على GitHub، أغلق التطبيق وافتحه مرتين ليأخذ النسخة الجديدة.
